# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-06

### Added
- Core Architecture: Clean Architecture + MVI + Modular Design.
- Local SDUI Server: Room Database acts as the Single Source of Truth.
- SDUI Engine: Recursive renderer, component registry, and design token resolver.
- Action Engine: Declarative action handling (Navigate, Snackbar, Dialog, BottomSheet, ToggleState).
- Design System: Token-based styling for Colors, Spacing, Typography, Shapes, and Elevation.
- Widgets: Complete library including HeroBanner, CarCard, HorizontalRail, CategoryChips, etc.
- CMS Server Panel: Structured form editor with Undo/Redo, JSON Preview, and Validation.
- Premium Landing: Animated, rich UI entry point.
- Multiple Screen Support: Initial seeding for Landing, Home, Deals, and Profile screens.
- Error Handling: Global Snackbar, Dialog system, and graceful renderer fallbacks.
- Versioning: Semantic versioning for JSON payloads and Renderer engine.
- Testing: Comprehensive Unit and Integration test suite.
